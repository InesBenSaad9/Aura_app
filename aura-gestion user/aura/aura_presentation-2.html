07 — Spécifications non fonctionnelles

Les contraintes techniques

⚡

Performance

UI < 100ms. Appels Claude et Whisper en thread background — jamais de gel d'interface.

BNF-01
🔒

Sécurité

Mots de passe hashés BCrypt. Clés API stockées côté serveur uniquement.

BNF-02
🖥️

Compatibilité

Java 17+. Fonctionne sur Windows, macOS et Linux sans configuration.

BNF-03
🛡️

Fiabilité

Gestion des erreurs API. Fallback si Claude ou Whisper est indisponible.

BNF-04
🤫

Confidentialité

Données vocales et émotionnelles jamais partagées sans consentement.

BNF-05
🔧

Maintenabilité

Architecture MVC stricte. Séparation DAO / Controller / View.
